هيكل المشروع (Monorepo)

pnpm workspace packages layout
workspace/
├── artifacts/
│ ├── norv-ai/ ← React + Vite frontend
│ │ ├── src/
│ │ │ ├── pages/ ← Route pages (dashboard, chat, quiz…)
│ │ │ ├── components/ ← Reusable UI (AccessGate, Countdown…)
│ │ │ ├── context/ ← AuthContext, ThemeContext, LangContext
│ │ │ └── i18n/ ← translations.ts (EN + AR)
│ └── api-server/ ← Express 5 backend
│ └── src/
│ ├── routes/ ← auth, access, chat, lectures, quiz…
│ ├── middleware/ ← auth.ts (JWT + access guard)
│ └── lib/ ← level.ts, helpers
└── lib/
├── db/ ← Drizzle schema + pg connection
├── api-spec/ ← openapi.yaml + orval.config.ts
├── api-client-react/ ← Generated hooks (orval output)
└── api-zod/ ← Generated Zod schemas (orval output)
