# Requirements Document

## 1. Application Overview

**Application Name**: Norv_ai.com

**Description**: A smart support platform designed for IT and Software Engineering university students, providing curated educational resources, AI-powered learning assistance, code debugging tools, automated assessment generation, and personalized career guidance.

---

## 2. Users and Usage Scenarios

### 2.1 Target Users
- IT and Software Engineering university students
- Students seeking structured learning resources aligned with university curricula
- Students requiring AI assistance for complex concepts and programming challenges

### 2.2 Core Usage Scenarios
- Accessing curated YouTube lectures filtered by course and topic
- Getting AI explanations for theoretical concepts and code
- Summarizing theoretical IT materials (Networks, Cybersecurity, Software Engineering)
- Writing, validating, and debugging code in a sandbox environment
- Generating practice quizzes from uploaded materials
- Assessing skill level and receiving career development recommendations

---

## 3. Page Structure and Functional Description

### 3.1 Page Hierarchy

```
Norv_ai.com Platform
├── Authentication Pages
│   ├── Login Page
│   └── Registration Page
├── Onboarding Page (Level Assessment)
├── Dashboard (Home Page)
├── Lecture Aggregator Page
├── AI Chatbot Page
├── Smart Summary Tool Page
├── Code Debugger & Sandbox Page
├── Quiz Generator Page
├── Career Advisor Page
├── Student Profile Page
└── Admin Panel
    ├── Lecture Management
    └── Curriculum Management
```

### 3.2 Functional Description by Page

#### 3.2.1 Authentication Pages

**Login Page**
- User inputs email and password to log in
- Support OAuth login (Google, GitHub)
- Link to registration page

**Registration Page**
- User inputs email, password, and basic information to create account
- Support OAuth registration
- After successful registration, redirect to Onboarding Page

#### 3.2.2 Onboarding Page (Level Assessment)

- Display onboarding quiz/form to assess student's current level and specialization
- Questions cover: Programming experience, familiar languages, IT sub-fields (Programming, Networks, Cybersecurity, AI/ML, etc.)
- Collect student's university, major, and year of study
- Store assessment results in student profile
- After completion, redirect to Dashboard

#### 3.2.3 Dashboard (Home Page)

- Display student's specialization and current level
- Show recent activity: recently accessed lectures, chatbot conversations, generated quizzes
- Display personalized recommendations: suggested lectures, learning paths, career advice
- Provide quick access links to all core features
- Show progress indicators for completed courses and assessments

#### 3.2.4 Lecture Aggregator Page

- Display curated YouTube lecture list organized by university course curricula
- Provide filter options:
  - Course name
  - Topic
  - Specialization (Programming, Networks, Cybersecurity, AI/ML, etc.)
  - Difficulty level (Beginner, Intermediate, Advanced)
- Each lecture entry shows: title, instructor, duration, difficulty level, related course
- Click lecture to open embedded YouTube player or redirect to YouTube
- Mark lectures as completed or save to favorites

#### 3.2.5 AI Chatbot Page

- Provide chat interface for multi-turn conversation with AI assistant (powered by LLM like Gemini via Edge Functions)
- Support input types: text questions, code snippets
- AI capabilities:
  - Explain complex IT concepts
  - Summarize academic materials
  - Answer programming questions
  - Explain code logic and syntax
- Display conversation history
- Allow starting new conversation or continuing previous ones

#### 3.2.6 Smart Summary Tool Page

- Allow user to upload theoretical IT materials (text files, PDFs) or paste text directly
- Supported content types: Networks, Cybersecurity, Software Engineering, etc.
- Generate smart summary with:
  - Conceptual highlights
  - Key points extraction
  - Structured outline
- Display original text and summary side by side
- Allow downloading or copying summary

#### 3.2.7 Code Debugger & Sandbox Page

- Provide code editor with syntax highlighting
- Support multiple programming languages
- User writes code in editor
- Click \"Check Code\" button to validate code
- If code is correct:
  - Highlight code in green
  - Display explanation of why code is efficient and correct
- If code has errors:
  - Pinpoint exact error location with line number
  - Explain why error occurred
  - Provide scientific fix suggestions
- Execute code in sandboxed environment and display output

#### 3.2.8 Quiz Generator Page

- Allow user to upload materials (text files, PDFs) or input text
- Select quiz type: Multiple Choice, Coding Questions, True/False, or Mixed
- Set number of questions
- Generate quiz automatically based on input material
- Display generated quiz with questions and answer options
- Allow taking quiz immediately or saving for later
- Show quiz results with correct answers and explanations

#### 3.2.9 Career Advisor Page

- Analyze student's performance data: completed courses, quiz scores, specialization, skill level
- Display personalized career development recommendations:
  - Suggested programming languages to learn
  - Recommended career fields matching current skills
  - Developmental paths with milestones
  - Skill gap analysis
- Show industry trends and job market insights relevant to student's specialization

#### 3.2.10 Student Profile Page

- Display student's basic information: name, email, university, major, year
- Show specialization and current level from assessment
- Display learning statistics: completed lectures, quiz scores, chatbot usage
- Allow editing profile information
- Show saved lectures and favorite resources

#### 3.2.11 Admin Panel

**Lecture Management**
- Add new YouTube lectures with metadata: title, URL, course, topic, specialization, difficulty level
- Edit or delete existing lectures
- Link lectures to university course curricula
- View lecture access statistics

**Curriculum Management**
- Create and manage course curricula
- Define course structure: topics, subtopics, learning objectives
- Map lectures to curriculum topics
- Set course difficulty levels and prerequisites

## 4. Business Rules and Logic

### 4.1 User Authentication and Authorization
- Support email/password authentication and OAuth (Google, GitHub)
- New users must complete onboarding assessment before accessing core features
- Admin users have access to Admin Panel; regular students do not

### 4.2 Lecture Filtering and Recommendation
- Filter results must match all selected criteria (course, topic, specialization, difficulty)
- Recommended lectures on Dashboard are based on student's specialization and current level
- Recently accessed lectures are stored per user session

### 4.3 AI Chatbot Interaction
- Chatbot uses LLM (Gemini) integrated via Supabase Edge Functions
- Conversation history is stored per user and can be retrieved
- Code snippets in chat are automatically detected and formatted with syntax highlighting

### 4.4 Smart Summary Generation
- Summary engine processes uploaded files or pasted text
- Extracts key concepts, highlights, and structured outline
- Summary length is proportional to input material length

### 4.5 Code Validation and Debugging
- Code is executed in sandboxed environment to ensure security
- Syntax checking and error detection are performed before execution
- Error messages include line number, error type, and fix suggestions
- Correct code is highlighted and explained for learning purposes

### 4.6 Quiz Generation Logic
- Quiz questions are generated based on content analysis of uploaded material
- Question difficulty matches material complexity
- Coding questions include test cases for validation
- Quiz results are stored in student profile for progress tracking

### 4.7 Career Advisor Recommendations
- Recommendations are generated by analyzing student's specialization, completed courses, and quiz performance
- Suggested career paths align with student's current skill level and interests
- Developmental paths include actionable steps and resource links

### 4.8 Data Storage and Retrieval
- User profiles, assessment results, lecture data, conversation history, quiz results, and progress data are stored in Supabase PostgreSQL database
- Edge Functions handle AI processing and code execution

## 5. Exceptions and Boundary Cases

| Scenario | Handling ||
|----------|----------|
| User uploads unsupported file format in Summary Tool | Display error message: \"Unsupported file format. Please upload text or PDF files.\" |
| AI Chatbot fails to respond due to API error | Display error message: \"AI service temporarily unavailable. Please try again later.\" |
| Code execution exceeds time limit in Sandbox | Terminate execution and display: \"Code execution timed out. Please optimize your code.\" |
| No lectures match selected filter criteria | Display: \"No lectures found. Try adjusting your filters.\" |
| User attempts to access Admin Panel without admin privileges | Redirect to Dashboard with message: \"Access denied. Admin privileges required.\" |
| Quiz Generator receives empty or invalid input | Display error: \"Please provide valid material to generate quiz.\" |
| OAuth login fails | Display error message and offer alternative login method (email/password) |
| User skips onboarding assessment | Redirect back to Onboarding Page with prompt: \"Please complete assessment to continue.\" |

## 6. Acceptance Criteria

1. User registers with email and password, completes onboarding assessment, and successfully accesses Dashboard
2. User applies filters on Lecture Aggregator Page and views curated YouTube lecture matching selected course and difficulty level
3. User opens AI Chatbot, asks a programming question, and receives accurate multi-turn explanation
4. User uploads theoretical IT material to Smart Summary Tool and receives structured summary with key points
5. User writes code in Code Debugger & Sandbox, submits for validation, and receives error pinpointing with fix suggestions (if error exists) or efficiency explanation (if correct)
6. User inputs material into Quiz Generator, generates quiz with multiple choice and coding questions, takes quiz, and views results with explanations
7. User accesses Career Advisor Page and views personalized career recommendations based on profile and performance data

---

## 7. Out of Scope for This Release

- Mobile native applications (iOS/Android)
- Offline mode or downloadable content
- Peer-to-peer collaboration features (group study, shared notes)
- Video conferencing or live tutoring integration
- Gamification elements (badges, leaderboards, rewards)
- Integration with university LMS (Learning Management Systems)
- Advanced analytics dashboard for students (detailed performance metrics, time tracking)
- Multi-language support (platform currently in English only)
- Social features (commenting, liking, sharing lectures)
- Payment or subscription system
- Third-party API integrations beyond specified LLM and OAuth providers
- Custom code execution environments for languages beyond initial supported set
- Automated plagiarism detection for code submissions
- Integration with external job boards or recruitment platforms
